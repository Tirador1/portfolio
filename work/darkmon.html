case 01 · darkmon

Darkmon

Darkmon. The dark web, turned into customer alerts.

threat intelligence · enterprise platform · backend

the story

A threat-intelligence platform for banks and governments, fed by the engine underneath.

Java · Spring Boot Python Crawlers & pipelines MISP Cortex XSOAR Global search

about the product

Darkmon is a threat-intelligence platform used by banks and governments. It watches the clear, deep and dark web for a company's leaked data: credentials, code, cards, look-alike domains, actor chatter.

the challenge

  1. 01

    Collect from places that resist collection: dark-web forums, Telegram, code hosts and paste sites, around the clock.

  2. 02

    Turn raw noise into matches: normalize, enrich and match every finding to a tenant's registered assets.

  3. 03

    Deliver where security teams already work: MISP feeds, Cortex XSOAR, SSO, one global search.

the approach

Crawlers and collectors feed pipelines; pipelines feed a matcher; the matcher feeds the APIs. Every screen the customers see is fed by that engine.

my role

Two years on the backend, end to end: the crawlers, the pipelines, the global search and the APIs.

The platform's biggest features are mine: code-leak monitoring across GitHub, GitLab, DockerHub, NPM and Gist; impersonation monitoring across nine platforms; the Cortex XSOAR pack live on the Palo Alto Marketplace; the MISP integration; enterprise SAML SSO, an MCP server and GDPR erasure workflows.

The UI in this chapter is the product my engine feeds, rebuilt with synthetic data.
